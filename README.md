# Exercícios de Lógica em Java

Repositório com exercícios iniciais de **lógica de programação em Java**.

Os códigos foram desenvolvidos como práticas acadêmicas para treinar entrada e saída de dados, operações matemáticas, condicionais e estruturas de repetição no terminal.

## Exercícios

- `Main` — exibe uma mensagem simples no terminal.
- `Verificar` — verifica se um número é par ou ímpar.
- `arit` — calcula a média de três notas.
- `calculodeIMC` — calcula o IMC com base no peso e altura informados.
- `oparit` — realiza operações básicas: soma, subtração, multiplicação e divisão.
- `tabuada` — exibe a tabuada de um número informado pelo usuário.

## Conceitos praticados

- Sintaxe básica do Java
- Variáveis
- Operadores aritméticos
- Condicionais
- Laços de repetição
- Entrada de dados com `Scanner`
- Saída de dados no terminal

## Tecnologias

- Java
- IntelliJ IDEA
